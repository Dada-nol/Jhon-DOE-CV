# Jhon DOE - CV en ligne

Ce projet est un modèle de CV en ligne responsive, conçu pour présenter de manière professionnelle le parcours et les compétences de Jhon DOE. Il est développé en HTML, SCSS et JavaScript, et peut être facilement personnalisé pour s'adapter à d'autres profils.

##  Structure du projet

- `index.html` : Page principale du CV.
- `assets/` : Contient les fichiers SCSS pour le style.
- `script.js` : Fichier JavaScript pour les interactions dynamiques.

##  Installation et utilisation

1. **Cloner le dépôt :**

   ```bash
   git clone https://github.com/Dada-nol/Jhon-DOE-CV.git
   cd Jhon-DOE-CV

2.Ouvrir le fichier index.html dans votre navigateur :

    Vous pouvez simplement double-cliquer sur le fichier index.html ou l'ouvrir avec votre éditeur de code préféré et utiliser une extension de serveur local pour le visualiser.

## Personnalisation

    Contenu : Modifiez le fichier index.html pour adapter les informations personnelles, l'expérience professionnelle, la formation, etc.

    Style : Les styles sont définis dans les fichiers SCSS situés dans le dossier assets/. Vous pouvez les modifier pour changer l'apparence du CV.

    Interactions : Le fichier script.js contient le code JavaScript pour les interactions dynamiques. Vous pouvez l'ajuster selon vos besoins.
